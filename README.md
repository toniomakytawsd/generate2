# ✨ Generator Nicków

Prosta i elegancka aplikacja okienkowa (GUI) do szybkiego generowania unikalnych nicków i kopiowania ich bezpośrednio do schowka.

---

## 🚀 Dla Użytkowników (Gotowy program .exe)

**Nie musisz instalować Pythona ani niczego konfigurować!**

1. Przejdź do sekcji **Releases** po prawej stronie repozytorium.
2. Pobierz plik `generate2.exe`.
3. Uruchom go dwuklikiem — program jest gotowy do działania.

---

## ✨ Funkcje aplikacji

* **Ciemny motyw (Dark Mode):** Nowoczesny i przyjemny dla oka interfejs.
* **Kopiowanie jednym kliknięciem:** Dedykowany przycisk z potwierdzeniem skopiowania tekstu do schowka.
* **Walidacja danych:** Zabezpieczenie przed pomyłkowym generowaniem pustych pól.
* **Samodzielny plik:** Brak konieczności instalacji dodatkowego oprogramowania.

---
